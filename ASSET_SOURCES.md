# 3D asset sources

The game loads the following individual GLB models from 3DAssets.dev. The source pages identify them as CC0 1.0 Universal, permitting modification and commercial use without attribution.

- Timber House Medium: https://3dassets.dev/assets/medieval-mmo-starter-realm-timber-house-medium-81d882c1
- Timber House Large: https://3dassets.dev/assets/medieval-mmo-starter-realm-timber-house-large-4ffa48c3
- Market Stall variants: https://3dassets.dev/assets/medieval-mmo-starter-realm-market-stall-e0677cc9
- Oak Tree: https://3dassets.dev/assets/medieval-mmo-starter-realm-oak-tree-c7fbe965
- Cobble Road Tile: https://3dassets.dev/assets/medieval-mmo-starter-realm-cobble-road-tile-9ec1d90e
- Wall Gatehouse: https://3dassets.dev/assets/medieval-mmo-starter-realm-wall-gatehouse-56290f64
- Stone Church: https://3dassets.dev/assets/medieval-mmo-starter-realm-stone-church-dc47dafb
- Village Tavern: https://3dassets.dev/assets/medieval-mmo-starter-realm-village-tavern-55158e5e
- Town Well: https://3dassets.dev/assets/medieval-mmo-starter-realm-town-well-2cdec208
- Town Wall Segment: https://3dassets.dev/assets/medieval-mmo-starter-realm-town-wall-segment-09028049

All listed assets are loaded from their permanent CDN URLs at runtime. The human characters remain the game's own procedural articulated meshes; a verified rigged human model and matching animation set are still required for a major character-quality upgrade.

## Character models

The game loads the Gobkit Human 003 pack at runtime from `https://gobkit.com/freebies/human003/`: `PeasantMilitia.glb`, `Priestess.glb`, `KnightCaptain.glb`, `Footman.glb`, and `Scout.glb`. Verify the publisher's current license terms before redistributing the model files or using them commercially.


## Locally generated GLB pack
The deployment workflow runs `tools/generate_assets.py` and publishes these locally generated files under `assets/`:
- `pressburg_house.glb`, `michalska_gate.glb`, `st_martin_church.glb`, `pressburg_tavern.glb`
- `town_well.glb`, `city_wall_segment.glb`, `cobble_tile.glb`
- `market_stall.glb`, `pressburg_tree.glb`, `oak_barrel.glb`, `wooden_cart.glb`

These are original low-poly meshes generated by the repository's own script. The character rigs remain external Gobkit GLBs and are not included in this local pack.
