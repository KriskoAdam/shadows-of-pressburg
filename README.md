# SHADOWS OF PRESSBURG — v0.5

Historická 3D akčná adventúra zasadená do Prešporka roku 1567. Prototyp používa Babylon.js z CDN a externé CC0 GLB modely historickej architektúry a rigované 3D postavy. Niektoré interakčné a kolízne prvky sú procedurálne.

## Spustenie
Hra je publikovaná cez GitHub Pages. Otvor webovú adresu projektu. Na načítanie Babylon.js je potrebné internetové pripojenie.

## Ovládanie
- Mobil: ľavý joystick na pohyb, pravá strana obrazovky na otáčanie kamery, tlačidlá akcií.
- PC: WASD/šípky, myš, Space, E, F, Shift, C, Q, Escape.

## Stav
Ide o hrateľný prototyp, nie dokončenú AAA hru. Mesto využíva externé GLB modely domov, trhových stánkov, brány, kostola, krčmy, studne, stromov a dlažby. Postavy sa načítavajú ako rigované GLB modely; hra zatiaľ nemá motion-capture animácie ani kompletný systém ukladania.
