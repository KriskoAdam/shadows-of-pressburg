# SHADOWS OF PRESSBURG — v0.4

Historická 3D akčná adventúra zasadená do Prešporka roku 1567. Prototyp používa Babylon.js z CDN a procedurálne vytvorené prostredie a postavy.

## Spustenie
Hra je publikovaná cez GitHub Pages. Otvor webovú adresu projektu. Na načítanie Babylon.js je potrebné internetové pripojenie.

## Ovládanie
- Mobil: ľavý joystick na pohyb, pravá strana obrazovky na otáčanie kamery, tlačidlá akcií.
- PC: WASD/šípky, myš, Space, E, F, Shift, C, Q, Escape.

## Stav
Ide o hrateľný prototyp, nie dokončenú AAA hru. Mesto a postavy sú procedurálne; zatiaľ neobsahuje profesionálne externé 3D modely, motion-capture animácie ani kompletný systém ukladania.
